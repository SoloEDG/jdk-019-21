# Vectora 矢量路径工具

安装：Node.js 22 环境下执行 `npm ci`。

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:8119。

## 智能吸附

拖动对象、锚点或贝塞尔手柄时会自动吸附，从容缩放、旋转后依然以屏幕像素为准（默认 12px）。

- **目标**：锚点、曲线交点、曲线最近点（长曲线中间也能吸附，不只是节点）、切线方向、等间距参考。
- **辅助线**：每条参考线都会标注命中的内容，例如 `Anchor 3 · Petal 2`、`Intersection · A × B`、`Tangent · Ref`、`Equal spacing · 60`；等间距参考线使用虚线并显示实测间距。
- **取舍**：接近多个候选时锁定最近命中的目标，只有更近的候选明显更优（<55%）才切换；目标消失或指针离开后立即释放，不会持续锁死。
- **精度**：所有吸附距离按 CSS 像素计算，写入文档的坐标保持浮点精度；移动过程始终基于手势起始快照，换目标不会累积误差。
- **临时关闭**：按住 `Alt` 立即恢复自由移动，松开后继续吸附；也可以直接取消工具栏的 `Snap` 开关。`Esc` 放弃当前手势。
- **撤销**：一次拖动（松开鼠标）只产生一条可撤销记录；没有实际位移的点击不产生记录。
- **可见性**：隐藏或锁定的对象既不能被编辑，也不会成为有效吸附目标（图层面板中的眼睛/锁按钮可切换）。
- **导出**：SVG 与本地存档只包含真实节点数据，参考线只存在于交互层，隐藏对象也不会出现在导出结果中。
